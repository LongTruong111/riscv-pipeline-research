# Signal Inventory v1 — Scoreboard Interface

## 1. Purpose

This inventory defines the DUT signals required by the future Cocotb
monitor, scoreboard, and coverage collector.

Signal paths are derived from RTL and confirmed against simulation
visibility where applicable.

The `dut.` prefix is intentionally omitted because the exact Cocotb
prefix depends on the selected TOPLEVEL.

---

## 5. Forwarding encoding

From ForwardingUnit RTL:

| Value | Source |
|---|---|
| 00 | Register File / no forwarding |
| 10 | EX/MEM |
| 01 | MEM/WB |
| 11 | Not generated by current RTL |

Therefore `11` is currently an illegal/unreachable forwarding-select
value for coverage purposes.

---

## 6. Flush semantics

`PcSel` is not only a PC mux select.

It is consumed by:

- the next-PC mux;
- IF/ID flush logic;
- ID/EX flush logic.

Therefore the verification logical name is:

`CTRL_FLUSH_REDIRECT`

rather than only `FLUSH_ID`.

---

## 7. Scoreboard commit interface

The preferred architectural write-back interface is:

(REG_WRITE_WB, REG_WRADDR_WB, REG_WRDATA_WB)

corresponding to:

(dp.reg_write_sig, dp.reg_num, dp.reg_data)

This interface is preferred over decoding the packed MEM/WB register
because the signals are explicitly exposed by the Datapath RTL.

Writes where destination register is x0 must not modify the reference
architectural state.

---

## 8. Sampling contract

### Pre-edge intent

Sample using:

FallingEdge(clk)
ReadOnly()

Used for:

- Reg_Stall
- PcSel
- FAmuxSel
- FBmuxSel
- reg_write_sig
- reg_num
- reg_data

These values describe control or commit intent that will be consumed at
the following RisingEdge.

### Post-edge state

Sample using:

RisingEdge(clk)
ReadOnly()

Used for:

- PC
- fetched instruction
- IF/ID state
- ID/EX state
- EX/MEM state
- MEM/WB state

---

## 9. RTL evidence

Datapath RTL establishes:

- `PcSel` as next-PC select and flush control.
- `Reg_Stall` from the HazardDetection unit.
- `reg_num = D.rd`.
- `reg_data = WRMuxResult`.
- `reg_write_sig = D.RegWrite`.
- `WB_Data = WRMuxResult`.

ForwardingUnit RTL establishes:

- `10` = EX/MEM forwarding.
- `01` = MEM/WB forwarding.
- `00` = no forwarding.

HazardDetection RTL establishes `Reg_Stall` from the load-use
dependency comparison.

---

## 10. VCD visibility

The baseline VCD confirms visibility of:

- PcSel
- Reg_Stall
- FAmuxSel
- FBmuxSel
- reg_write_sig
- reg_num
- reg_data
- WB_Data

Therefore all currently selected scoreboard/control signals are
observable in simulation.
